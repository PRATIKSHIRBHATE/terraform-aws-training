Task2:

Adding a Single Pod to Cluster IP Service using YAML files

1.Create a deployment from the following configuration


apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx-ctr
        image: nginx:1.15.4
        ports:
        - containerPort: 80


2.Deploy the application

kubectl create -f deploy2.yaml


3.Create a clusterIP service for the above-created deployment

apiVersion: v1
kind: Service
metadata:
  name: nginx-svc
  labels:
    app: nginx
spec:
  type: ClusterIP
  ports:
  - port: 80
    targetPort: 80
    protocol: TCP
  selector:
    app: nginx

4.Deploy the service

kubectl create -f cservice.yaml

5.Get the list of services:

kubectl get svc

NAME         CLUSTER-IP   EXTERNAL-IP   PORT(S)   AGE
kubernetes   10.0.0.1     <none>        443/TCP   1h
nginx-svc    10.0.0.134   <none>        80/TCP    8s

6.Check the details of the pod which got created

[root@k8s-master ~]# kubectl get pods -o wide
NAME                               READY   STATUS      RESTARTS   AGE    IP          NODE           NOMINATED NODE   READINESS GATES

7.Check the service details and observe if pod ip has been mapped to service

kubectl describe svc:
